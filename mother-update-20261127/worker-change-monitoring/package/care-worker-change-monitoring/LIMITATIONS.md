# 0.1.0-preview.1 구현 범위와 제한

- Python 3.10 이상. 현재 로컬 worker-notes snapshot 계약용이며 타 버전 자료 구조는 사전 확인한다.
- 원본 생성기에 출력 기관 경로 제한과 Python 최적화 실행 차단만 추가했다. 원본 PC의 설치본은 변경하지 않았다.
- 기간/대상 필터가 없으며 검증된 보관월 전체를 읽는다. 불완전월, 해시/기관 불일치는 처리를 중단한다.
- 기존 문서 자동 재사용과 실제 상담 근거 자동 반영은 미구현이다. 새 출력 폴더만 허용한다.
- 직원명 기준 관측이다. 동명이인/계약 차수/공동제공은 추가 검토가 필요하다. 시간중복은 경고가 있는 events에 남으므로 확정 변경 수로 합산하지 않는다.
- 모든 문서는 상담 미확인 예시 초안이다. 예시 문구나 예정시간은 실제 상담 사실이 아니다.
- 입력 검증 일부는 assert를 사용하므로 -O/-OO 실행을 명시적으로 차단한다. 향후 명시적 오류 검사로 전환할 후보이다.
- Python 및 문서 변환 도구는 ZIP에 포함하지 않는다. 설치 스크립트는 스킬 파일만 설치한다.
- 이 버전의 자동시험은 가상자료 생성과 설치 보존 확인이다. 대상 PC의 DOCX/PDF/PNG 시각 검증·실제 기관 업무는 별도로 필요하다.
- 롱텀 공식 서명 업데이트가 아닌 별도 공개 prerelease이다. 해시 비교는 파일 무결성 검사이며 발행자 서명이 아니다.
