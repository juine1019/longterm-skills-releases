# 변경사유와 상담내용 예시

각 쌍은 가상 예시다. 근거가 없는 건에 사용할 때 두 서술란 모두 예시 표시를 유지한다. 상담 대상자는 본인, 상담방법은 유선상담을 가정한 문구다. 실제 발언·실시 사실은 건별로 확인한다.

| 번호 | 변경사유 예시 | 상담내용 및 상담 대상자 의견 예시 |
|---|---|---|
| 1 | 기존 요양보호사의 개인 일정으로 해당일 서비스 제공이 어려워 대체 직원을 배정함. | 직원 변경 후 이용에 불편함이 있었는지 본인에게 유선으로 확인함. 필요한 도움을 받아 불편함은 없었으며, 다음 방문 일정도 미리 알려주면 좋겠다고 말씀하심. |
| 2 | 기존 요양보호사의 건강상 사유로 근무가 어려워 제공직원을 변경함. | 변경된 직원의 도움 방식과 의사소통에 대해 본인과 유선상담함. 설명을 천천히 해주어 이해하기 편했고, 당분간 같은 직원이 방문하기를 원한다고 말씀하심. |
| 3 | 기존 요양보호사의 연차 사용으로 해당 기간 대체 직원을 배정함. | 대체 직원의 서비스 제공 후 불편한 점을 본인에게 유선으로 확인함. 전반적으로 만족하나 자주 사용하는 물건은 기존 위치에 두어 달라고 요청하심. |
| 4 | 기존 요양보호사의 퇴사로 지속적인 서비스 제공을 위해 담당 직원을 변경함. | 새로운 직원에게 도움받은 소감을 본인에게 유선으로 확인함. 처음에는 낯설었으나 필요한 사항을 설명하며 이용하고 있고, 익숙해질 때까지 같은 직원의 방문을 원한다고 말씀하심. |
| 5 | 수급자가 희망하는 제공시간과 기존 직원의 근무시간이 맞지 않아 직원을 변경함. | 변경된 방문시간과 서비스 이용에 대해 본인과 유선상담함. 평소 생활시간에 맞게 도움받을 수 있어 편하며, 현재 방문시간을 유지하고 싶다고 말씀하심. |
| 6 | 기존 직원과 도움 방식에 대한 의견 차이가 있어 수급자의 요청을 반영하여 직원을 변경함. | 직원 변경 후 도움 방식이 본인의 요구에 맞는지 유선으로 확인함. 요청사항을 먼저 물어보고 도와주어 편했고, 앞으로도 충분히 설명하며 진행해 주기를 원한다고 말씀하심. |
| 7 | 기존 요양보호사의 근무지역 변경으로 방문을 지속하기 어려워 다른 직원을 배정함. | 새 직원의 방문과 서비스 제공에 대해 본인과 유선상담함. 방문시간을 잘 지켜주었고 도움받는 데 큰 불편은 없었으며, 식사 준비 방법은 조금씩 맞춰가고 있다고 말씀하심. |
| 8 | 기존 요양보호사의 교육 참석으로 해당일 대체 직원을 배정함. | 대체 직원에게 도움받으며 불편한 점이 있었는지 본인에게 유선으로 확인함. 필요한 도움은 받았으나 이동을 도울 때는 조금 더 천천히 진행해 달라고 요청하심. |
| 9 | 일시 대체 기간이 종료되어 기존 요양보호사가 다시 서비스를 제공함. | 기존 직원 복귀 후 이용 상황을 본인에게 유선으로 확인함. 평소 생활습관을 잘 알고 있어 편안하며, 대체 기간에도 필요한 도움을 받았다고 말씀하심. |
| 10 | 기존 요양보호사의 장기 부재로 안정적인 서비스 제공을 위해 담당 직원을 변경함. | 변경된 직원의 서비스 제공과 적응 상태를 본인에게 유선으로 확인함. 대화와 도움 방식에 점차 익숙해지고 있으며, 방문할 직원이 다시 바뀌면 사전에 안내해 달라고 요청하심. |

임시 대체·복귀 등의 정황이 확인되면 해당 쌍을 우선 사용한다. 무작위 선택은 확인되지 않은 예시를 채우는 경우에 사용하고 사례 번호를 manifest에 보존한다.
