# 롱텀 스킬 Windows 설치 파일

[Windows 설치 도우미 1.1.2 다운로드](https://github.com/juine1019/longterm-skills-releases/releases/download/v1.1.2/LongtermSetup-1.1.2.exe)

이 저장소는 검수된 코드 패키지와 설치 안내만 배포합니다. 개발 저장소와 기관별 업무자료는 공개하지 않습니다. GitHub 로그인 없이 설치 파일을 받을 수 있습니다.

## 현재 배포 상태

1.1.2는 **설치 확인용(Pre-release)** 입니다. 마더 PC의 별도 폴더 설치와 가상 시험을 통과했습니다. 실제 새 PC에서의 첫 설치·기존 설치 업데이트·센터 자체 수정 보존은 해당 PC에서 확인해야 합니다. stable 자동 업데이트 feed는 아직 발행하지 않았습니다.

## 사용 순서

1. Windows 10/11의 로컬 NTFS 디스크를 사용하고, Codex와 Aside 앱을 준비해 직접 로그인합니다. Aside CLI도 필요합니다.
2. 설치 도우미를 다운로드합니다. SHA256SUMS.txt의 해시와 파일 해시를 확인할 수 있습니다.
3. EXE를 열고 짧은 업무 폴더를 선택한 뒤 설치를 시작합니다. 필요한 도구가 없을 때만 도구 설치 허용을 선택합니다. WinGet이 없거나 권한/설치 정책으로 거절되면 안내된 도구를 직접 준비합니다. Windows 보안 정책을 우회하지 마세요.
4. 기존 설치 폴더에서는 자체 스킬·기관 설정·자료를 보존합니다. 서로 충돌하거나 점유/미확인 실행이 있으면 중단합니다. 기존 베타 폴더를 지우거나 덮어쓰지 마세요.
5. 완료 후 Codex에서 업무 폴더를 열고, 설치 도우미의 **Codex 시작 문구 복사** 내용을 붙여 넣습니다. 도구를 새로 설치했다면 Codex·Aside를 완전히 닫았다가 다시 엽니다.
6. 기관 정책 채택과 기관/종사자/업무데스크 로그인은 직접 진행합니다. 설치 과정에서 실제 업무 체크·승인·게시·저장·전송·통보를 하지 않습니다.

이 EXE에는 Windows Authenticode 서명이 적용되지 않았습니다. Windows 보안 알림 또는 조직 정책 차단이 나타날 수 있습니다. 차단되면 배포 관리자에게 문의하세요. Ed25519 공개키는 향후 업데이트의 신뢰 확인용이며 Windows 실행 파일 서명과 별개입니다.

## 업데이트와 자체 스킬

설치기는 공식 공개 저장소와 업데이트 공개키를 로컬에 고정합니다. 같은 버전 재실행은 재설치하지 않으며, 다른 키/주소를 기존 설정에 덮어쓰지 않습니다. 향후 서명된 stable feed가 발행되면 Codex에 “롱텀 스킬 업데이트 확인해 줘” 또는 “롱텀 스킬 업데이트해 줘”라고 요청할 수 있습니다. 현재 feed 미발행 상태의 확인 실패를 업데이트 성공으로 보지 마세요.

자체 수정과 새 버전이 충돌하면 자동 덮어쓰기나 자동 삭제를 하지 않습니다. 기관 업무자료는 각 PC 로컬에 보관합니다.
